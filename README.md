# 🏗️ Annamalaiyar Construction Website

A modern, responsive business website for **Annamalaiyar Construction** - a trusted construction company based in Tirupur, Tamil Nadu.

[![TypeScript](https://img.shields.io/badge/TypeScript-5-blue?style=for-the-badge&logo=typescript)](https://www.typescriptlang.org/)

## 🌟 Features

- **Responsive Design** - Mobile-first approach, works on all devices
- **Modern UI/UX** - Smooth animations with Framer Motion
- **SEO Optimized** - Proper meta tags and semantic HTML
- **Contact Form** - Working email integration with Web3Forms
- **WhatsApp Integration** - Floating button for instant customer contact
- **Instagram Link** - Social media integration in navbar
- **Project Gallery** - Filterable portfolio (Completed/Ongoing)
- **Fast Performance** - Optimized images and lazy loading

## 📄 Pages

| Page | Description |
|------|-------------|
| **Home** | Hero slider, About, Services, Projects, Stats, CTA |
| **About** | Company story, mission, vision, and team info |
| **Services** | Comprehensive list of construction services |
| **Projects** | Filterable gallery of completed and ongoing projects |
| **Contact** | Contact form, location map, and contact details |

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **UI Components:** Radix UI + shadcn/ui
- **Animations:** Framer Motion
- **Forms:** React Hook Form + Zod validation
- **Email:** Web3Forms API
- **Icons:** Lucide React
- **Fonts:** Inter, Poppins (Google Fonts)
- **Analytics:** Vercel Analytics
- **Deployment:** Vercel
